# Como contribuir

Toda contribuição útil conta: corrigir uma frase, compartilhar uma descoberta ou documentar uma solução.

## Iniciantes — contribua pelo navegador

1. Abra a pasta do assunto e leia seu README.
2. Para sugerir algo sem editar arquivos, abra uma issue e use o modelo de contribuição.
3. Para editar, abra o arquivo no GitHub, clique no lápis e faça sua alteração. Se o GitHub pedir, crie um fork (uma cópia no seu perfil).
4. Descreva o que mudou e clique em **Propose changes**. Abra um pull request (pedido de revisão) para a branch `main` do repositório original.
5. Aguarde a revisão e responda aos comentários. Não é necessário saber programar para melhorar a documentação.

## Intermediários — envie uma contribuição completa

1. Crie um fork e uma branch com nome descritivo, como `adiciona-recurso-css`.
2. Use a categoria e o modelo adequados. Procure antes para evitar duplicatas.
3. Confira links, instruções e exemplos; informe o ambiente em que testou.
4. Abra um pull request pequeno, com objetivo e forma de verificação.

## Avançados — ajude a manter a qualidade

Revise contribuições com explicações acolhedoras, reproduza exemplos e proponha melhorias em uma issue antes de reorganizar muitas pastas. Inclua dependências e limitações relevantes. Evite ferramentas ou processos adicionais sem necessidade clara.

## Padrão comum

- Escreva em português do Brasil, com títulos objetivos e caminhos em minúsculas, sem acentos e separados por hífen.
- Uma contribuição deve resolver um assunto de cada vez.
- Dê crédito à fonte e informe a licença ou permissão de uso quando compartilhar código ou conteúdo de terceiros. Prefira links a copiar materiais.
- Não inclua senhas, tokens, dados pessoais nem arquivos `.env` reais.
- Informe o que foi verificado e o que ainda não foi testado. Conteúdo gerado por IA também precisa de revisão.
- Mantenha o respeito: critique a proposta, não a pessoa.

## Conversas da comunidade

Use [Discussions no resources](https://github.com/Criandos-Sites/resources/discussions) para descobertas, ajuda, projetos e ideias. Use issues para alterações concretas neste repositório.
