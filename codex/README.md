## Como adicionar

Crie uma pasta com nome descritivo e um README usando o [modelo de skill](../templates/README-skill.md). Inclua as instruções reutilizáveis, requisitos e um exemplo verificável. Declare a ferramenta, a versão ou o ambiente testado e o método de aplicação; não presuma que todos os assistentes importam o mesmo formato.
