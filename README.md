# Skills · Criandos-Sites

Uma biblioteca de instruções reutilizáveis, organizadas por assistente. Cada contribuição deve explicar como aplicar e verificar as instruções no ambiente declarado. A pasta identifica o destino; não garante compatibilidade automática entre ferramentas.

## Categorias

- [Claude](claude/README.md) — Instruções e skills destinadas ao Claude.
- [Codex](codex/README.md) — Instruções e skills destinadas ao Codex.
- [ChatGPT](chatgpt/README.md) — Instruções e fluxos documentados para o ChatGPT.
- [Gemini](gemini/README.md) — Instruções e fluxos documentados para o Gemini.
- [Universal](universal/README.md) — Instruções adaptáveis a diferentes assistentes.

## Comece aqui

Escolha uma categoria e leia suas orientações. As pastas começam como espaços de contribuição; ainda não há um catálogo de itens validados.

Para adicionar uma skill, crie `<assistente>/<nome-da-skill>/README.md` usando o [modelo de documentação](templates/README-skill.md). Inclua ao lado o arquivo de instruções adequado ao ambiente e registre o item no índice da categoria.

Leia [como contribuir](CONTRIBUTING.md). Sugestões e correções também podem ser enviadas pelas issues.
